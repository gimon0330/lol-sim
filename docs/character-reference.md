# 이즈리얼 참고 자료와 구현 범위

확인일: 2026-09-24

- 공식 PC LoL 챔피언 페이지: https://www.leagueoflegends.com/ko-kr/champions/ezreal/
- 기본 외형 렌더: https://static.wikia.nocookie.net/leagueoflegends/images/7/7e/Ezreal_Render.png/revision/latest?cb=20231105074037
- 시네마틱 모델의 여러 방향 참고: https://nicolascollings.com/videogames

금발의 쓸어 넘긴 머리, 고글, 밝은 속옷, 갈색 탐험가 재킷과 부츠, 푸른 옷깃, 어두운 바지, 가죽 벨트, 금색 장갑과 푸른 마력 보석을 기하 모델로 재구성했습니다. 첨부된 참고 이미지 파일이나 공식 게임 에셋은 배포하지 않습니다. 형태와 비율을 단순화한 팬 모델입니다.

## 스킬 구현 상태

공식 PC LoL 페이지의 패시브 및 Q/W/E/R 명칭을 기준으로 개발합니다. Wild Rift 데이터와 혼용하지 않습니다.

| 슬롯 | 명칭 | 현재 상태 |
|---|---|---|
| 패시브 | 끓어오르는 주문의 힘 | 미구현 |
| Q | 신비한 화살 | 발사·충돌·피해·쿨타임 감소 구현 |
| W | 정수의 흐름 | 발사·표식·갱신·만료·추가 피해 구현 |
| E | 비전 이동 | 순간이동·표적 탐색·유도탄 구현 |
| R | 정조준 일격 | 준비 동작·관통 투사체 구현 |

원작과 같은 스킬 동작을 목표로 할 때는 우선 기준 PC 패치를 고정해야 합니다. 사거리, 투사체 속도, 시전 시간, 피해 계수, 마나, 재사용 대기시간, Q 적중 시 재사용 대기시간 감소, W 부착/폭발, E 표적 선정, R 관통과 피해 감소, 패시브 중첩을 각각 검증해야 합니다. 현재 버전은 사용자가 지정한 Q/W 규칙과 시험용 E/R 수치를 사용합니다. 자세한 값은 `spells.md`와 `src/combat/spells.js`를 참고하세요. 적은 게임 화면에 아직 등장하지 않습니다.
