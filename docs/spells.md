# 스킬 구현 계약

## 요청에서 확정한 값

- Q: 피해 50, 쿨타임 3초. 살아 있는 적에게 맞으면 Q 자신을 포함한 Q/W/E/R의 남은 쿨타임을 각각 1초 줄입니다. 0초보다 작아지지 않으며 빗나가면 감소하지 않습니다.
- W: 첫 적에게 5초 표식을 부착하고 즉시 피해를 주지 않습니다. 다른 Q/E/R이 맞으면 추가 피해 100과 해당 스킬 피해를 합산합니다. 표식은 한 번만 폭발합니다. W 재적중은 피해 없이 지속시간만 갱신합니다.
- E: 커서 방향의 짧은 순간이동. 도착한 위치에서 평타 사거리 내 적이 있으면 자동 공격합니다. 이동 거리와 탐색 범위는 요청한 20~30 중 25를 채택했습니다.
- 이번 커밋에서는 실제 적이나 기본 공격 기능을 추가하지 않습니다.

## 임시 수치 및 동작 결정

| 항목 | 값 |
|---|---|
| Q/W 사거리 | 45 |
| Q/W 속도 | 40 / 30 |
| Q/W 준비 시간 | 0.15초 |
| W 쿨타임 | 6초 |
| E 쿨타임 / 자동 공격 피해 | 10초 / 50 |
| E 후딜레이 | 0.25초 |
| R 쿨타임 / 피해 | 20초 / 200 |
| R 준비 시간 / 사거리 / 속도 | 1초 / 120 / 35 |

단위는 현재 연습장의 월드 좌표입니다. 원작의 게임 내 거리 단위와 동일하지 않습니다. E 목적지는 이동 거리 25와 연습장 경계를 모두 지킵니다. E의 자동 공격은 도착 시 한 번만 표적을 선정하는 유도탄이며, W 표식 우선 → 가까운 거리 순으로 고릅니다. 적이 없으면 순간이동만 합니다. 표적이 사라지거나 죽으면 유도탄은 사라집니다.

Q/W는 첫 번째 충돌에서 소멸하고 R은 관통하며 투사체 한 개가 같은 적에게 중복 피해를 주지 않습니다. R은 적 종류별 피해 감소를 아직 적용하지 않습니다. 쿨타임은 시전 시작 때 소비되며 준비 중 이동/추가 시전은 불가합니다. S/Escape는 이동 및 조준 선택을 취소하지만 이미 시작한 시전은 취소하지 않습니다. W는 실제 **적중 시점**부터 5초입니다.

## 적 연동

`SpellSystem` 생성 시 `getEnemies()`가 현재 활성 적 객체 배열을 반환해야 합니다. 같은 적은 동일한 객체 참조를 유지하세요.

```js
const enemies = [];
const enemy = {
  position: new THREE.Vector3(0, 0, 5),
  radius: 0.65,
  health: 500,
  alive: true,
};
// 다음 적 구현 커밋에서 enemies에 실제 적 객체를 등록합니다.
```

현재 `src/game.js`의 `enemies`는 빈 배열입니다. 피해 로직은 `health`를 감소시키며 0이면 `alive=false`를 기록합니다. 적 렌더링/사망 처리 코드는 이 값을 읽거나 `damage` 이벤트를 구독하면 됩니다. `mark/unmark/detonate` 이벤트는 적을 감싸는 금색 고리와 폭발 이펙트로 연결되어 있습니다. 충돌은 XZ 평면의 원형 충돌체와 이동 선분의 최초 교점으로 계산합니다.

## 검증

- `node tests/spells.mjs`: W→Q 피해 150, Q 전체 쿨타임 감소, W 갱신/5초 만료, Q 첫 충돌, R 준비/관통/중복 피해 방지, E 거리/표식 우선/최단거리/무대상/사망, 미스 및 초기화.
- `node tests/movement.mjs`: 기존 이동 기능과 Q/W/E/R 키 입력, UI 쿨타임, 순간이동, R 시전 상태, 초기화 및 실제 Three.js 이펙트 객체 생성.

테스트 데이터로만 적을 생성합니다. 실제 게임에는 적이 없습니다. 테스트는 WebGLRenderer를 대체하며 3D 픽셀 출력과 시각적 완성도를 보증하지 않습니다. 이전 검증에서 클라우드 브라우저의 WebGL이 비활성화된 것을 확인했습니다.
